# Write a template and send it to Meta

A template is a message Meta approves before you can send it to a customer outside the 24-hour window. You write it on the **Templates** page of Ebda Chat and it is created on your own WhatsApp account.

## Steps
1. Open **Templates** and choose **New template**.
2. **What is it for?** Pick one of three cards: a service message about an order (confirmation, shipping, status), a marketing message (offers), or a verification code. Marketing messages need the customer's opt-in and are billed at the marketing price.
3. **Language and title.** Pick the language. The title is only for you; customers never see it. The technical name Meta uses is made for you and is under **Advanced settings**.
4. **Write the text.** Press **Add a variable** where the customer name or order number goes. A variable looks like {{1}}. Write an example value for every variable: Meta needs the examples to review the template.
5. **Optional parts.** A header, a footer, and buttons (quick replies, a link, a call button, a copy-code button).
6. **Fix what the page tells you.** The page checks Meta's rules while you type, beside the field. Errors stop the send button. A warning (for example wording that looks like an offer inside a service message) you tick to confirm.
7. **Review and send to Meta.** You see the message as the customer will see it. **A template sent to Meta cannot be taken back.** You can edit or delete it later, but not recall the submission. Confirm to send.
8. Meta reviews it, up to 24 hours. The status on the page changes by itself.

## Limits Meta sets (the page applies them for you)
- Text: up to 1024 characters. Variables are numbered {{1}}, {{2}} in order with no gaps, and the text cannot start or end with a variable.
- Header: text only for now, up to 60 characters, at most one variable. Footer: up to 60 characters, no variables.
- Buttons: up to 10 in total; up to 2 link buttons and 1 call button; each label up to 25 characters. Quick replies and the other buttons must be grouped, not mixed.
- Verification codes: the wording is fixed by Meta, no links and no emojis, and the code is valid for 1 to 90 minutes.
- Meta allows 100 template submissions per hour and 250 templates on an unverified business (6,000 verified).

## Which type?
- **Service message:** about an order the customer made. It must not be promotional.
- **Marketing message:** anything with an offer or a discount. If you file an offer as a service message, Meta changes it to marketing and tells you after you send: the customer must have agreed to marketing, each message costs more, and it counts toward your campaigns.
- **Verification code:** a one-time code.

## If you are on the shared number
You cannot create templates yourself. Open **Templates**, use the ready-made ones, or press **Request a service template** and the team creates it for you. Marketing messages need your own number.
