# Send a picture or a file to a customer

## Steps
1. Open the conversation. The 24-hour window must be open (the customer wrote less than 24 hours ago); otherwise the paperclip is disabled.
2. Press the paperclip (**Attach a file**).
3. Pick the file from your device. It is prepared and sent to the customer.

## Types and sizes WhatsApp allows
| Type | Largest size |
|---|---|
| JPG or PNG image | 5 MB |
| MP4 video | 16 MB |
| OGG audio with the Opus codec | 16 MB |
| PDF document | 50 MB |

Any other type is refused as "unsupported". The app checks the file itself, not its name, so renaming a file to get it through does not work. HEIC pictures and .mov videos must be converted to a normal JPG or MP4 first.

## When the 24 hours have passed
WhatsApp allows neither files nor free text outside the window (error 131047). The only way is a template approved by Meta ([templates guide](04-templates-and-the-24-hour-window.md)). The composer then shows **Choose a template**.

## If the file did not go
- **The file is over the limit in the table:** make it smaller or send it as another type.
- **The message is marked failed:** press **Try again** ([failed messages guide](22-failed-messages-and-sending-limits.md)).
