# Plans

Status lives in the program register (`Ebda-AI-Studio/business/ebda/EBDA-PROGRAM-REGISTER.md`, section 2). `docs/plans/` = open work only; `done/` = shipped (kept for history, never deleted).

A plan moves to `done/` when its register row is LIVE-VERIFIED, MERGED-NOT-VERIFIED-LIVE or DECIDED-NOT-TO-BUILD. Plans whose row is PARTIAL, OPEN-PR, NOT BUILT, IN BUILD or BLOCKED stay here. Plan checkboxes are not status.
