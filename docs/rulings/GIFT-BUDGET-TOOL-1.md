# Ruling GIFT-BUDGET-TOOL-1 (controller, 2026-11-19)

**Decision:** a gift / budget ask is graded on its OUTCOME, not on which product tool served it. (1) In the golden rubric either `search_catalog` (maxPrice = the budget) or `recommend_products` (basis `budget`, maxPrice = the budget) passes (`toolsAny`), and ANY product shown (a card or a text hit) that costs more than the budget fails as `over_budget_shown`, counted under CHAT-EVAL-BAR-1's hard gate "no invented money/promise facts". (2) An explicit ask must never end empty because of rationing: when `recommend_products` answers `rate_limited`, `nothing_to_recommend` or `already_recommended_this_turn` and the customer asked (products, ideas, a gift, a budget), the agent calls `search_catalog` with the same maxPrice and then `show_products` in the SAME turn. The rubric fails `gave_up_on_explicit_ask` (reply outcome with nothing shown). Done in the prompt (`agent-copy.ts`, recommendations rule) and in the tool results' `note` (`recommend.ts`), which is what the model reads at the moment it is refused.

**Evidence:** `recommend.ts` enforces the ceiling (basis budget filters `price <= maxPrice`; similar/complement/after_order send `maxPriceMinor` and re-filter) but rations (RECS_PER_DAY per customer, no repeats), so the earlier rubric (search_catalog only) graded tool choice, not outcome. Tests: `test/chat-golden-eval.test.ts` negative controls (over-budget card fails, gave-up fails, recommend_products with the ceiling passes, stopping after a refused recommendation fails), golden cases `gift-ration-ar-1` / `gift-ration-en-1` (customer already at the ration limit: the harness primes 3 `recs:` rows, so a live run starts from the same state), `test/agent-recommendations.test.ts` (refused result carries the search_catalog fallback; prompt line present; mutation-checked).

**Cost if wrong:** a looser tool check could hide a model that ignores budgets (the over-budget outcome check covers it); the shared prompt gained one sentence for the default model too (WA-MODEL-FLAG-1's "byte for byte" covers the flag-gated additions, not the common rules).
